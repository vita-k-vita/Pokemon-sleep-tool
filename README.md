# Pokemon-sleep

ポケモンスリープの個体評価・育成・料理計画をまとめたツールです。`index.html` をブラウザで開くと使えます。画像の文字読み取りには、読み取りエンジンや言語データの取得時にインターネット接続が必要です。

## アップデート履歴

日付は GitHub への公開日（日本時間）です。

### 2026-11-25 — プルダウン・スキル補正・レベル入力

- スマホのプルダウンが短いタップで開くようにしました。
- スキル発動回数のイベント補正（1.25倍）を追加しました。発動期待値と計算対象のスキル効果に反映します。
- 個体の比較レベルをLv.1〜70で自由に入力できるようにしました。選んだレベルに応じて食材枠とサブスキル枠を切り替えます。


### 2026-11-23 — 個体画像の読み取り・スマホ操作・分割睡眠

- 能力画面で名前を特定できないときに、ポケモンの画像から種族を推定するようにしました。ニックネーム付きの個体にも使えます。
- スマホのプルダウンを、画面内に収まるスクロール式メニューに変更しました。
- フィールド別出現一覧に分割睡眠の試算を追加しました。現在のカビゴンエナジーと1回目の睡眠時間を入れると、各回の出現匹数と、目標匹数に必要な睡眠時間の目安が分かります。合計8時間30分、両回とも同じエナジーで計算します。
- 期待値ランキングを初期状態で折りたたみました。
- 個体のスキル発動回数や総エナジーの数値をタップすると、その項目の順位に切り替わるようにしました。
- 個体の評価カードにミニタブを追加しました。総エナジー・通常収集の食材数・スキル発動回数・きのみ数を選ぶと、1日あたりの期待値と全体順位が切り替わります。

[初回更新のコミット](../../commit/046df2fbfef55a407533eba83887b5652b8f66a1)


### 2026-11-16 — パーティ料理計算と収録データの更新

- パーティ料理計算を追加。チーム編成画像からメンバーの名前とレベルを読み取り、選んだ食材構成から料理ごとの食数と不足食材を試算できます。
- エルフーンを期待値ランキングに追加し、収録は130種・フォームに。ひとくちナッツと新料理3品を追加し、レシピは計81品になりました。
- 個体画像の読み取りを改善。進化前・中間進化の名前から最終進化先を候補にでき、食材アイコンが一部隠れた画像でも、見えている部分から候補を推定します。

[公開コミット](../../commit/c41071a3da0557caea3aef4eef981848a0e82715)

### 2026-11-15 — スマホ表示の改善

- スマホでタブ・入力欄・フィールドの出現表を見やすく調整し、2個体比較をランキングの下に移動しました。
- 食材のアイコン選択とサブスキル欄をコンパクトにし、狭い画面でも操作しやすくしました。

[レイアウト更新](../../commit/582a8c033a640bc508f483368256d851bac00ffd) · [入力欄の更新](../../commit/8ab71609e430c0d5203ee26034dff42ba55a5672)

### 2026-11-15 — 初回公開

- **期待値ランキング・2個体比較**：最終進化を中心に129種・フォームを収録。性格・食材・サブスキルを選び、食材数・スキル発動回数・総エナジーなどを比較できます。4時間／6時間ごとの回収、所持上限、カビゴンの好物きのみ、Lv.70の第4サブスキルに対応しています。能力画面の画像からも個体情報を入力できます。
- **必要アメ計算**：現在Lv.と目標Lv.から、必要なアメとゆめのかけらを試算。性格のEXP補正やアメブーストに対応しています。
- **レシピ食材計算**：複数の料理を選び、料理ごとの食数に応じて必須食材を合算できます。
- **フィールド別出現一覧**：通常7フィールドとEX2フィールドを収録。ランク・睡眠タイプ別の出現ポケモン、必要エナジー、出現数の目安を確認できます。

[初回公開コミット](../../commit/c917054bbede92f9ba211ea14d0988cf21266d62)
